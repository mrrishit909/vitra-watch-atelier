# Color system: black lacquer and metal

| Token | Hex | Where |
|---|---|---|
| Obsidian | #050505 | Page and canvas clear colour; the dial's default finish |
| Champagne Gold | #D7BA75 | Bezel, indices, hands, crown, UI accents, active station |
| Ivory | #F2EBDD | Text, light colour, ivory-enamel dial |
| Gunmetal | #25272A | Bridges, matte dial finish |
| Ruby Jewel | #A6112D | Seconds hand, jewels, the intro's opening jewel, ruby lacquer dial |
| Steel | #B7C0C7 | Case metal, caseback |

Light is the material system: a Room environment map plus a champagne key, with per-material reflection strength. Swapping a finish eases colour, metalness, roughness and reflection together over about 0.4 s, so a metal change reads as the light finding a different surface.
